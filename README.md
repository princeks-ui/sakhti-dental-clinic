# Sakthi Dental Clinic Website

React + Vite website built strictly from the provided ShadowFox client brief.

## Run

```bash
npm install
npm run dev
```

Then open the local Vite URL shown in the terminal.

## Images

Place the client-provided Drive images/icons in:

`public/images/`

The code already references the image filenames used by the treatment cards and hero section. Replace the placeholder files with the actual client assets from the provided Drive folder.
